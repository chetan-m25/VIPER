# VIPER – Snake Game  🐍

VIPER is a modern, web based Snake game built using **HTML, CSS, and Vanilla JavaScript**.  
This project was created to deeply understand **core JavaScript concepts** and learn how browser based games work in real scenarios.

## Live Demo
🔗 **Play here:** https://viper-game.netlify.app/

## About the Project

This project focuses more on logic and learning than visuals.

While building VIPER, I worked on implementing real time game logic, handling different input methods, and making the game usable across both desktop and mobile devices. Small animations and UI feedback were added to keep the experience smooth and engaging.

## What I Learned

- Implementing game logic using core JavaScript
- Managing game states (start, pause, resume, game over)
- Handling keyboard and mobile touch controls
- Using timers and intervals for gameplay and time tracking
- Increasing difficulty dynamically by controlling game speed
- Storing and retrieving data using **localStorage**
- Designing responsive layouts for different screen sizes
- Adding small animations for better user experience
- Understanding how web based games are rendered and updated

## Features

- Classic Snake gameplay
- Pause / Resume functionality
- Progressive difficulty
- High score persistence
- Mobile friendly controls
- Responsive layout
- Smooth UI interactions

## Project Purpose

This project was built as a **learning and practice exercise** to strengthen JavaScript fundamentals and understand how interactive web games are developed without using any frameworks.
